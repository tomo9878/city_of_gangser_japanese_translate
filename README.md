# City of Gangsters 非公式日本語化

**City of Gangsters**（Steam 版）を日本語で遊ぶための非公式の訳ファイルです。

> [!IMPORTANT]
> - これは有志による**非公式**の日本語化です。開発元・販売元の**公認ではありません**。
> - 日本語化による不具合を**開発元・販売元に問い合わせないでください**。おかしいと思ったら、まず英語に戻して同じことが起きるか確かめてください。
> - 利用は自己責任でお願いします。

## 入れ方

1. このページ右側の **Releases** から、いちばん新しいリリース（Latest）を開き、**`CityOfGangsters_JA.zip`** をダウンロードします。
2. ZIP を右クリック →「**すべて展開**」します。中に `jp.txt`・`jp2.txt`・`jptut.txt` の3つがあります。
3. ゲームを終了した状態で、3つのファイルをゲームの次のフォルダにコピーします。

   ```
   （Steam のフォルダ）\steamapps\common\City of Gangsters\CoG_Data\StreamingAssets\Loc
   ```

   よくある場所: `C:\Program Files (x86)\Steam\steamapps\common\City of Gangsters\CoG_Data\StreamingAssets\Loc`
   （Steam でゲームを右クリック →「管理」→「ローカルファイルを閲覧」で開いたフォルダの `CoG_Data\StreamingAssets\Loc`）
4. ゲームを起動し、設定の言語で **「日本語」** を選びます。

ゲームが言語の追加に対応しているので、ゲームのファイルは書き換えません。

## 元に戻す

ゲームの言語を English に戻します。ファイルも消したいときは、`Loc` フォルダの `jp.txt`・`jp2.txt`・`jptut.txt` を削除してください。

## ゲームが更新されたら

訳ファイルは更新で消えることはありませんが、増えた文章は英語のまま出ます。新しい版が出たら、同じ手順で上書きしてください。

- AI 翻訳をもとに手直ししたものです。英語の約1万1千項目のうち、約1万項目が日本語になっています（数値や記号だけの項目は英語と同じです）。
- おかしな訳があれば Issues でお知らせください。
